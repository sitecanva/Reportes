# TNCC - Reporte Combinado Cobre | Fibra

Dashboard Ejecutivo e Interactivo de la Tasa Neta de Crecimiento (TNCC) para tecnologías **Aba Ultra (Fibra)** y **Aba Cobre**, desarrollado para Mercadeo Hogares - Mercados Masivos (VPSS) con la identidad gráfica de **iPulso**.

## 🌐 Enlaces Públicos (GitHub Pages)

- **URL Directa TNCC:** [https://sitecanva.github.io/Reportes/TNCC/](https://sitecanva.github.io/Reportes/TNCC/)
- **URL Principal:** [https://sitecanva.github.io/Reportes/](https://sitecanva.github.io/Reportes/)

## 🚀 Características Principales

- **Multi-Vista Reactiva:**
  - Vista Combinada (Fibra & Cobre)
  - Aba Ultra (Fibra Óptica)
  - Aba Cobre (Red de Cobre)
- **Visualización de Series Temporales:**
  - TNCC mensual y acumulado.
  - Cartera de suscriptores y balance neto.
  - Dinámica de instalaciones y retiros.
- **TNCC Analytics Studio (Panel Externo):**
  - Carga masiva de métricas mediante Excel (`.xlsx`), CSV, texto delimitado o imagen.
  - Recálculo matemático y estadístico en tiempo real de ratios, balances e indicadores de aceleración/desaceleración.
  - Edición en vivo de títulos, períodos y metadatos.
  - Descarga de reportes HTML 100% autónomos y autocontenidos sin dependencias externas.
- **Diseño Responsive:**
  - Optimizado para pantallas de teléfonos inteligentes, tabletas y monitores de escritorio.
  - Selector de modos adaptable que previene desbordamientos en pantallas ultra-compactas (hasta 320px).
